# CLI Usage: agent-reasoning-mcp

Command-line reference for `@putervision/agent-reasoning-mcp`.

```bash
# Start MCP server on stdio transport
agent-reasoning-mcp run

# Initialize workspace, database, and agent rules
agent-reasoning-mcp init [--project <slug>]

# Run diagnostic health checks
agent-reasoning-mcp doctor

# Inspect active database tables
agent-reasoning-mcp inspect

# Verify SHA-256 Merkle audit chain
agent-reasoning-mcp audit
```
