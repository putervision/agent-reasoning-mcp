🏛️ BDI Cognitive Architecture

A mathematically rigorous, explainable BDI (Belief-Desire-Intention) loop designed to bridge sensory perception and high-frequency execution.

📡 1. Belief Maintenance

Structured belief state where every fact carries confidence that decays exponentially over time: B(t) = B₀ · e^(-λt). Perceptions refresh confidence; stale assumptions are culled automatically via TTL sweeps.

🎯 2. Hierarchical Goal DAGs

Complex objectives decompose into directed acyclic graphs of sub-goals. Progress dynamically rolls up from leaves to roots, preventing duplicated effort and circular dependencies.

⚖️ 3. Expected Utility Theory

Candidate actions are ranked using multi-attribute expected utility: E[U] = ∑ wᵢ · uᵢ across calibrated weights (Aggression, Caution, Greed, Exploration, Efficiency, and Cooperation).

🛡️ 4. Quantitative Risk Assessment

Every proposal undergoes risk evaluation measuring failure probability, reversibility penalty, and worst-case blast radius before selection, preventing catastrophic actions.

⚡ 5. Intention Dispatch Queue

Selected top actions become firm intentions dispatched via wire contract to runtime behavior engines (such as behavior-mcp) with priority preemption and execution timeouts.

🔄 6. Reactive Replanning & Audit

When environmental blockers invalidate assumptions, the replanner recalculates alternative paths, culls unviable intentions, and logs decisions to a tamper-evident SHA-256 Merkle audit trail.

🚀 Quickstart & Client Integration

Add agent-reasoning-mcp to your AI coding assistant with zero external dependencies.

1. Global Installation

Install globally via npm for CLI and server usage:

npm install -g @putervision/agent-reasoning-mcp

2. Client Configurations

Claude Code CLI

claude mcp add agent-reasoning-mcp -- npx -y @putervision/agent-reasoning-mcp

Cursor IDE (.cursor/mcp.json)

{ "mcpServers": { "agent-reasoning-mcp": { "command": "npx", "args": ["-y", "@putervision/agent-reasoning-mcp"] } } }

Gemini CLI

gemini mcp add agent-reasoning-mcp npx -y @putervision/agent-reasoning-mcp

3. Health & Database Verification

Verify installation and audit SQLite database health:

agent-reasoning-mcp doctor
